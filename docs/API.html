colab-rich API 文件

適合 Google Colab 和 Python 初學者的簡單 Rich 輸出工具

這個 library 把 Rich 的常用功能變成簡單函式。你只需要傳入文字、list 或 dictionary， 不需要建立 class，也不需要學習 Rich 的 Console。

基本輸出 表格 進度列 Markdown 面板 程式碼 清單和並排 JSON Colab 互動元件 完整例子

安裝

在 Google Colab 的 cell 中執行。這個基本套件已包含 Rich 和 ipywidgets：

!pip install colab-rich

然後從 colab_rich 匯入需要的函式：

from colab_rich import title, success, table

基本輸出

print_text(message, style=None)

顯示普通文字。message 可以是文字、數字或其他 Python 資料。

from colab_rich import print_text

print_text("你好，Colab！")

預期 terminal 輸出：

$ 你好，Colab！

title(message, style="bold blue", align="center")

顯示一個有分隔線的標題，適合分開程式不同部分的輸出。

from colab_rich import title

title("第一部分：資料輸入")

預期 terminal 輸出：

──────────────── 第一部分：資料輸入 ────────────────

success(message, prefix="✓")、info()、warning() 和 error()

用不同顏色顯示成功、提示、警告和錯誤訊息。每個函式都只需要一個訊息。

from colab_rich import error, info, success, warning

info("程式正在開始")
success("資料已經儲存")
warning("還有一項資料未輸入")
error("找不到檔案")

預期 terminal 輸出：

ℹ 程式正在開始
✓ 資料已經儲存
! 還有一項資料未輸入
✗ 找不到檔案

table(headers, rows, title=None, *, header_style="bold magenta", show_lines=False, expand=False)

用整齊的表格顯示資料。第一個參數是欄位名稱，第二個參數是資料列。

table(headers, rows)

from colab_rich import table

table(
    ["姓名", "分數"],
    [
        ["小明", 90],
        ["小華", 85],
    ],
)

預期 terminal 輸出：

┏━━━━━━┳━━━━━━┓
┃ 姓名 ┃ 分數 ┃
┡━━━━━━╇━━━━━━┩
│ 小明 │ 90   │
│ 小華 │ 85   │
└──────┴──────┘

每一列的資料數量必須和欄位數量相同：

# 正確
table(["水果", "數量"], [["蘋果", 3], ["香蕉", 5]])

# 不正確：第二列少了一項資料
table(["姓名", "分數"], [["小明", 90], ["小華"]])

show_progress(current, total, label="進度", *, width=20, complete="█", remaining="░", show_count=False)

顯示簡單進度列，適合放在 for loop 中。

from colab_rich import show_progress

for number in range(1, 6):
    show_progress(number, 5, "處理中")

預期 terminal 輸出：

處理中: [████████████████████] 100.0%

實際執行 loop 時會顯示五行，分別是 20%、40%、60%、80% 和 100%。

  • current：目前完成的數量。
  • total：總數量，必須大於 0。
  • label：進度列的文字，可以省略。

markdown(message, code_theme="monokai")

將 Markdown 文字顯示成格式化內容。

from colab_rich import markdown

markdown("""
# 今日報告

這是 **重要文字**。

- 第一點
- 第二點
""")

預期畫面：

今日報告

這是 重要文字。

• 第一點
• 第二點

panel(message, title="", border_style="cyan", *, expand=True)

在有框線的面板中顯示重點內容。第二個參數是面板的小標題，可以省略。

from colab_rich import panel

panel("請記得檢查答案。", "小提示")

預期 terminal 輸出：

╭────────────── 小提示 ──────────────╮
│ 請記得檢查答案。                           │
╰────────────────────────────────────────────╯

code(source, language="python", *, theme="monokai", line_numbers=True, word_wrap=False)

以語法顏色和行號顯示程式碼。預設語言是 Python。

from colab_rich import code

code("""name = '小明'
print(name)
""")

預期 terminal 輸出：

1 name = '小明'
2 print(name)

也可以指定其他常見語言：

code("console.log('Hello');", "javascript")
code("<h1>Hello</h1>", "html")

清單和並排項目

bullet_list(items, bullet="•", bullet_style="bold green")

將 list 中的每個項目顯示成一行清單。

from colab_rich import bullet_list

bullet_list([
    "開啟 Google Colab",
    "輸入程式碼",
    "執行程式",
])

預期 terminal 輸出：

• 開啟 Google Colab
• 輸入程式碼
• 執行程式

columns(items, *, equal=True, expand=False)

將簡短項目並排顯示。太長的句子不適合使用這個功能。

from colab_rich import columns

columns(["紅色", "綠色", "藍色"])

預期 terminal 輸出：

紅色                 綠色                 藍色

show_json(data, *, indent=2, sort_keys=False)

將 dictionary 或 list 以容易閱讀的 JSON 樣式顯示。

from colab_rich import show_json

student = {
    "name": "小明",
    "score": 90,
    "passed": True,
}

show_json(student)

預期 terminal 輸出：

{
  "name": "小明",
  "score": 90,
  "passed": true
}

資料可以是 dictionary、list、文字、數字、True、False 或 None。

Google Colab 互動元件

互動元件使用 Google Colab 支援的 ipywidgets。先匯入 Colab 的 display 函式，再顯示元件。

button(label, action=None, *, style="primary", tooltip=None, disabled=False)

建立一個按鈕。action 是按下按鈕後執行的零參數函式。 library 會處理按鈕 event 的細節。 

from IPython.display import display
from colab_rich import button, success

def say_hello():
    success("你好！你按下了按鈕。")

display(button("按我", say_hello))

預期 Colab 畫面：

[ 按我 ]

按下按鈕後，結果會顯示在按鈕下面：

✓ 你好！你按下了按鈕。

text_box(label, value="", *, placeholder="", disabled=False)

建立單行文字輸入框。使用 .value 讀取輸入的文字。

from IPython.display import display
from colab_rich import text_box

name = text_box("你的名字")
display(name)

print(name.value)

預期 Colab 畫面：

你的名字: [                    ]

select_box(label, options, *, value=None, disabled=False)

建立下拉選單。使用 .value 讀取目前選擇。

from IPython.display import display
from colab_rich import select_box

color = select_box("選擇顏色", ["紅色", "綠色", "藍色"])
display(color)

print(color.value)

預期 Colab 畫面：

選擇顏色: [紅色        ▼]

check_box(label, value=False, *, disabled=False)

建立核取方塊。.value 會是 True 或 False。

from IPython.display import display
from colab_rich import check_box

finished = check_box("我已完成練習")
display(finished)

print(finished.value)

預期 Colab 畫面：

☐ 我已完成練習

互動元件完整例子

from IPython.display import display
from colab_rich import button, select_box, success, text_box

name = text_box("你的名字")
color = select_box("喜歡的顏色", ["紅色", "綠色", "藍色"])

def show_answer():
    success(f"{name.value} 喜歡 {color.value}。")

display(name)
display(color)
display(button("顯示答案", show_answer))

按下按鈕後的預期結果：

✓ 小明 喜歡 綠色。

完整小例子

from colab_rich import (
    bullet_list,
    code,
    markdown,
    show_json,
    success,
    table,
    title,
)

title("Python 小報告")
markdown("這是一個 **學生資料** 報告。")
table(
    ["姓名", "分數"],
    [["小明", 90], ["小華", 85]],
)
bullet_list(["兩位同學已完成測驗", "平均分數是 87.5"])
code("print('報告完成！')")
show_json({"average": 87.5, "passed": True})
success("報告完成！")

預期 terminal 輸出會包含以下內容：

─────────────── Python 小報告 ───────────────
這是一個 學生資料 報告。
┏━━━━━━┳━━━━━━┓
┃ 姓名 ┃ 分數 ┃
┡━━━━━━╇━━━━━━┩
│ 小明 │ 90   │
│ 小華 │ 85   │
└──────┴──────┘
• 兩位同學已完成測驗
• 平均分數是 87.5
✓ 報告完成！

初學者提示

  1. 先學習 title()、success() 和 table()。
  2. 熟悉後再嘗試 markdown()、panel() 和 code()。
  3. 每個函式都可以單獨使用，不需要建立 class。
  4. Textual 暫時不是這個 library 的一部分；本 library 現階段專注於在 Colab 顯示內容。

提示：terminal 輸出的顏色由 Rich 控制。HTML 文件使用相近的顏色作為示意；表格寬度可能因 terminal 字型而略有不同。
